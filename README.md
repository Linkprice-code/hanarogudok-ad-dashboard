# 삼성하나로 구독 광고 리포트

네이버 SA · 네이버 GFA · 카카오 통합 대시보드입니다. `data` 폴더의 CSV 두 개를 수기로 교체하면 화면에 반영됩니다.

## 데이터 업로드 방법

GitHub 저장소 → `data` 폴더 → **Add file → Upload files** 로 같은 이름의 파일을 덮어쓰면 1~2분 뒤 반영됩니다.

### data/daily.csv (요약 · 유입 추이 · 매체별 성과)

| 날짜 | 매체 | 지출 | 노출 | 클릭 | 전환수 |
|---|---|---|---|---|---|
| 2026-10-01 | 네이버 SA | 203992 | 8419 | 344 | 19 |
| 2026-10-01 | 네이버 GFA | 104546 | 48944 | 357 | 12 |
| 2026-10-01 | 카카오 | 89862 | 33107 | 232 | 7 |

- 날짜 × 매체당 한 줄. 매체명은 `SA` / `GFA` / `카카오` 가 들어가 있으면 자동 인식합니다.

### data/keywords.csv (SA 키워드별 성과)

| 날짜 | 키워드 | 지출 | 노출 | 클릭 | 전환수 |
|---|---|---|---|---|---|
| 2026-10-01 | 삼성 구독 | 23500 | 735 | 47 | 2 |

- 네이버 검색광고 보고서 CSV를 내려받은 그대로 `keywords.csv` 이름으로 올리면 됩니다.
- `daily.csv` 에 네이버 SA 행이 없으면 이 파일의 합계를 SA 실적으로 사용합니다. (GFA · 카카오만 `daily.csv` 에 넣으면 됩니다)
- 보고서를 받을 때 **검색 유형** 항목을 포함해 주세요. 키워드가 `-` 인 확장 검색 행을 `확장 검색` 으로 묶어서 표시합니다. (검색 유형이 없으면 `(키워드 없음)` 으로 표시)
- `날짜` 열이 없으면 기간 필터 없이 업로드된 전체를 합산해서 보여줍니다.

### data/gfa.csv (GFA 매체 그룹 · 게재위치 · 연령 · 성별)

- 네이버 GFA 성과 보고서(광고 그룹 단위)의 `result.csv` 를 `gfa.csv` 로 이름만 바꿔 올리면 됩니다.
- 보고서를 만들 때 **기간(일별), 게재 위치, 연령 및 성별** 항목을 포함해 주세요.
- `daily.csv` 에 네이버 GFA 행이 없으면 이 파일의 합계를 GFA 실적으로 사용합니다.
- 캠페인 단위 보고서와 광고 그룹 단위 보고서는 합계가 같으므로 하나만 올리면 됩니다.

### 공통 규칙

- 열 순서는 상관없고, 열 이름은 `노출수`, `클릭수`, `광고비`, `총비용(VAT포함,원)` 같은 광고 관리자 원본 이름도 인식합니다.
- CTR · CPC · CPA는 자동 계산하므로 넣지 않아도 됩니다.
- `총비용` 열은 그대로 **지출**로 표시합니다.
- 숫자의 쉼표, `원`, `%` 는 있어도 됩니다. 엑셀에서 저장한 CSV(EUC-KR)도 읽습니다.
- 첫 줄의 `# SAMPLE` 은 샘플 데이터 안내 배너를 띄우는 표시입니다. 실제 데이터에는 넣지 마세요.

## GitHub Pages 배포

1. GitHub에서 새 저장소 생성 (Public)
2. `index.html`, `data` 폴더를 업로드
3. Settings → Pages → Branch를 `main` / `(root)` 로 저장
4. `https://<아이디>.github.io/<저장소명>/` 로 접속
